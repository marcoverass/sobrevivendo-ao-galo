# Assets

Organizacao simples para as artes do jogo.

## Pastas

- `raw/`: arquivos originais baixados da internet
- `sprites/`: sprites finais usados pelo jogo
- `tiles/`: tilesets e partes de fundo
- `ui/`: elementos de interface
- `credits/`: anotacoes de licenca e origem dos assets

## Sugestao de uso

1. Baixe o pack original e coloque em `raw/`
2. Copie apenas os arquivos que vao entrar no jogo para `sprites/`, `tiles/` ou `ui/`
3. Anote a origem e a licenca em `credits/`

## Estrategia recomendada

- usar pack pronto para NPCs e fundo
- adaptar o Galo manualmente para dar identidade propria ao projeto
