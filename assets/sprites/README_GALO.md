# Galo do evento

O jogo agora usa este arquivo:

- `assets/sprites/galo_evento.png`

## Recomendacao

Edite um galo do jeito que voce quiser e salve como:

- `galo_evento.png`

Preferencias:

- fundo transparente
- formato PNG
- desenho horizontal, olhando para a direita
- tamanho simples, depois o jogo redimensiona na tela
